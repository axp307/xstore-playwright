# Agent guide

This repo runs `.xstore` test scripts (plain-text steps matched against protected keywords) with Playwright.

- **Writing/editing `.xstore` scripts or adding new keywords:** read [`.github/skills/xstore-scripts/SKILL.md`](.github/skills/xstore-scripts/SKILL.md) first.
- Commands: `npm run typecheck`, `npm test`, `npm start -- --script <file> --config <json> --dry-run`.
- Architecture overview: [`docs/wiki/Technical-Overview.md`](docs/wiki/Technical-Overview.md).
